# Supported Versions

| Version | Supported | Python | PostgreSQL | Redis |
| --- | --- | --- | --- | --- |
| `main` (pre-release) | Best effort | 3.10+ | 16+ | 7+ |
| Stable releases | Security fixes for the latest stable minor | Defined per release | 16+ | 7+ |

Setu Gateway is currently pre-release. Compatibility commitments will be formalized at the first stable release.
