# RFC-0002: System Architecture

- **Status:** Accepted

## Decision

Setu Gateway is a modular monolith with explicit domain boundaries, deployed first through Docker Compose and also supported through Kubernetes/Helm. Every tenant resource is scoped by `organization_id`. The public gateway exposes versioned, OpenAI-compatible APIs, including chat, responses, embeddings, images, audio, and models.

The runtime provides timeouts, retries, circuit breaking, health checks, load balancing, database-backed routing configuration, encrypted PostgreSQL secrets with optional Vault support, and an event-driven integration model. Arq/Redis-based asynchronous jobs are preferred for background work.

## Rationale

A modular monolith reduces early operational overhead while preserving a migration path to independent services if scale requires it.
