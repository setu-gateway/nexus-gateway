# RFC-0000: Engineering Principles

- **Status:** Accepted
- **Project:** Setu Gateway

## Decision

Setu Gateway is guided by: developer-first design; security by default; OpenAI compatibility; provider and plugin neutrality; API-first behavior; backward compatibility; event-driven integration; cloud-native deployment; zero-trust tenancy; performance and observability; documentation as code; comprehensive testing; and no vendor lock-in.

Every feature must materially improve at least one of: **faster, cheaper, smarter, safer, or easier**. The architecture must remain simpler than the feature set.
