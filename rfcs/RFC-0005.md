# RFC-0005: Intelligent Routing Engine

- **Status:** Accepted

## Decision

Routing is a deterministic, policy-first pipeline: enforce policies; optionally classify workload; match capabilities; filter health and compliance; estimate cost and latency; score candidates; select a model and fallback chain. AI-assisted classification is optional and must be disableable; deterministic rules remain available.

Every selection records an explanation, alternatives, confidence, policy results, estimates, and actual outcome. Admins can simulate decisions and policies without making provider calls. Support A/B, canary, and shadow-routing architecture, but stage their rollout by maturity.

## Future compatibility

Nexus Flow-style pluggable request nodes are reserved for a later release; v1 remains a focused gateway.
