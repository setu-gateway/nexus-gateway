# RFC-0003: Identity and Tenancy

- **Status:** Accepted

## Decision

Each new user receives a personal organization and default project. Organizations can have many projects, members, provider credentials, policies, and API keys. Users may belong to multiple organizations.

Default roles are Owner, Admin, Developer, Billing, Security, and Viewer. Custom roles use composable permissions. API keys are project-scoped, hashed rather than stored in plaintext, and support expiry, revocation, rotation, usage tracking, and least-privilege scopes.

## Core entities

`users`, `organizations`, `organization_members`, `projects`, `project_members`, `roles`, `permissions`, `role_permissions`, `sessions`, `oauth_accounts`, and `api_keys`.
