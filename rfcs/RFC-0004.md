# RFC-0004: Provider System and Capability Registry

- **Status:** Accepted

## Decision

Provider-specific code is implemented as plugins behind a stable provider interface. The gateway core works with normalized requests and capabilities, not provider-specific conditionals. Providers declare support for chat, streaming, embeddings, vision, audio, image generation, tool calling, structured output, reasoning, context limits, regions, and pricing.

Provider lifecycle: install, validate manifest and compatibility, approve permissions, register, health-check, activate. A provider sandbox validates authentication, requests, streaming, error behavior, and rate-limit handling before a plugin is enabled.

## Consequence

The router can select a healthy model by required capabilities and policy rather than hardcoded provider names.
