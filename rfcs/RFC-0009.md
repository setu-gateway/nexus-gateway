# RFC-0009: Plugin SDK

- **Status:** Accepted

## Decision

External integrations use an official, versioned Setu Plugin SDK rather than internal imports. Plugin categories include providers, authentication, storage, analytics, billing, notifications, firewalls, routers, classifiers, cache backends, cost estimators, policy evaluators, and future workflow nodes.

Every plugin has a manifest with identity, version, SDK compatibility, capabilities, and declared permissions. Lifecycle hooks include load, start, request/response processing where allowed, health checks, and shutdown. v1 plugins run in-process with validated interfaces and permissions; the SDK preserves a future path to process or container isolation.

Plugins are classified as Core, Verified, or Community. Marketplace installation, signatures, compatibility checks, permission approval, telemetry, and supported hot reload are part of the platform direction.
