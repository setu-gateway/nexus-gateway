# RFC-0010: Public API and SDKs

- **Status:** Accepted

## Decision

Setu provides versioned REST APIs and OpenAI-compatible inference endpoints. Management APIs expose organizations, projects, keys, providers, models, routing policies, plugins, usage, and security controls. Inference begins with `/v1/chat/completions`, then expands to responses, embeddings, images, audio, and models.

All errors follow a stable envelope containing a machine code, human message, request ID, and retryability. SSE is the primary streaming protocol. Every request has a trace ID and inspectable routing record.

Nexus-specific capabilities include routing explain, routing simulation, cost estimation, benchmarks, and Time Machine replay. Maintain Python and TypeScript SDKs plus a CLI. OpenAPI is the canonical contract and can generate SDK foundations; ergonomic layers remain handwritten.
