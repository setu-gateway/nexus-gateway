# RFC-0006: Gateway Request Lifecycle

- **Status:** Accepted

## Decision

Requests proceed through: authentication and authorization; tenant resolution; quota and rate-limit checks; firewall and preprocessing; optional classification; policy evaluation; routing; cache lookup; provider execution with retry/fallback; response validation; response delivery; asynchronous analytics, audit, billing, events, and webhooks.

Streaming preserves provider semantics through normalized SSE responses while recording trace context and terminal usage. Each stage emits structured events. Request payload retention is configurable and minimized by default.

## Approved extensions

Prompt Cache Intelligence supports exact cache first and optional semantic cache. Time Machine supports privacy-aware, opt-in request replay and policy comparison. Shadow routing and response scoring are retained for later milestones.
