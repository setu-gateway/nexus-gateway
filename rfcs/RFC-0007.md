# RFC-0007: Security and Authentication

- **Status:** Accepted

## Decision

Setu applies zero trust: authenticate, authorize, resolve tenant and scope, then evaluate policy on every request. v1 supports API keys, JWT, sessions, and Google/GitHub OAuth. OIDC, SAML, service accounts, and machine identities are future work.

Secrets—including provider credentials, OAuth tokens, and webhook secrets—use authenticated encryption and can later integrate external KMS or Vault. Tenant isolation applies to database queries, cache keys, event streams, rate limits, storage, and audit logs.

The security architecture includes configurable firewall and secret-scanning policies, immutable audit logs, BYOK and managed keys, scoped API keys, an emergency lockdown mechanism, and provider trust scores. Compliance packs and policy simulation are planned extensions.
