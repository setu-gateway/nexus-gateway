# RFC-0001: Foundation and Monorepo

- **Status:** Accepted
- **Project:** Setu Gateway

## Context

Setu needs a contributor-friendly foundation for a Python gateway, TypeScript applications, SDKs, plugins, documentation, and infrastructure.

## Decision

Use a monorepo with `apps/`, `packages/`, `plugins/`, `infrastructure/`, `docs/`, `rfcs/`, `examples/`, and `tests/`. The backend is Python 3.13+, FastAPI, SQLAlchemy 2, Alembic, Pydantic v2, PostgreSQL, Redis, and async I/O. The web experience uses React, TypeScript, Tailwind, and TanStack Query. Use `uv` for Python and `pnpm` for JavaScript. Use short-lived branches from a deployable `main` branch and semantic versioning.

## Consequences

Shared interfaces and tooling live centrally; modules remain independently testable. The repository will initially be larger than a simple frontend/backend layout, in exchange for stable extension boundaries.
