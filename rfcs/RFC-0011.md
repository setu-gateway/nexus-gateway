# RFC-0011: Repository, Services, and Deployment

- **Status:** Accepted

## Decision

Setu is packaged as a monorepo. The gateway remains a single deployable modular monolith, with dashboard, docs, playground, CLI, SDKs, plugin SDK, and shared contracts arranged as applications/packages. Redis Streams are the initial event transport; future transports are replaceable adapters.

Docker Compose is the official local and self-hosted path, with profiles for development, testing, production, and benchmarks. Kubernetes/Helm is the official scalable deployment path. Observability uses OpenTelemetry, Prometheus, Grafana, Loki, and Tempo.

CI validates formatting, linting, types, unit and integration tests, plugin compatibility, dependency/security scans, builds, generated OpenAPI, and documentation. Releases publish images, packages, charts, release notes, and changelogs. `setu doctor`, self-test, configuration validation, and upgrade checks are required developer-experience goals.
