# OpenAI Provider Setup

Setu Gateway natively proxies OpenAI endpoints including Chat Completions, Embeddings, and Image Generation.

## Setup

Set your OpenAI API key in your environment:

```bash
OPENAI_API_KEY=sk-...
```

## Supported Models

- `gpt-4o`
- `gpt-4o-mini`
- `o1-preview`
- `text-embedding-3-small`
