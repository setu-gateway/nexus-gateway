# Observability & Analytics

Setu Gateway tracks latency per provider, prompt tokens, completion tokens, and dollar costs.

## Metrics Export

Metrics are exposed via standard Prometheus format at `/metrics`:

- `gateway_requests_total`
- `gateway_token_usage_total`
- `gateway_request_duration_seconds`
- `gateway_cost_usd_total`
