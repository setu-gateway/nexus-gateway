# Request Execution Flow

1. **Ingress**: Client issues HTTP request to `/v1/chat/completions`.
2. **Authentication**: Auth plugin validates bearer token and rate limit budget.
3. **Routing**: Router evaluates model mapping, load balancing, and fallbacks.
4. **Cache Lookup**: Cache layer checks Redis for hit. If hit, returns immediately.
5. **Upstream Dispatch**: Proxy streams payload to destination LLM provider.
6. **Egress & Analytics**: Response is streamed back to client; token metrics recorded.
