# Introduction to Setu Gateway

Setu Gateway simplifies LLM infrastructure by acting as an OpenAI-compatible proxy between your applications and underlying model providers.

## Key Features

- **OpenAI-Compatible API**: Seamlessly drop into existing OpenAI SDK implementations.
- **Intelligent Routing**: Route requests based on cost, latency, rate limits, or custom rules.
- **Unified Authentication**: Manage API keys, user roles, and access controls in one place.
- **Built-in Caching**: Reduce latency and provider costs with semantic and exact response caching.
- **Observability**: Track request metrics, token usage, and cost analytics in real time.
- **Extensible Plugins**: Customize request lifecycle behavior with custom plugins.
