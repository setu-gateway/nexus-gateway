# Ollama Provider Setup

Connect self-hosted local models running on Ollama.

## Setup

Set your Ollama host URL:

```bash
OLLAMA_BASE_URL=http://localhost:11434
```

## Supported Models

- `llama3.2`
- `mistral`
- `qwen2.5`
