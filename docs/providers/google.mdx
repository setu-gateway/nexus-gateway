# Google Gemini Provider Setup

Integrate Google Gemini models through Nexus Gateway proxying.

## Setup

Set your Gemini API key:

```bash
GEMINI_API_KEY=AIzaSy...
```

## Supported Models

- `gemini-1.5-pro`
- `gemini-1.5-flash`
- `gemini-2.0-flash-exp`
