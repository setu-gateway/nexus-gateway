# Local Development Setup

1. Fork and clone the repository:

```bash
git clone https://github.com/nexus-gateway/nexus-gateway.git
cd nexus-gateway
```

2. Install workspace dependencies:

```bash
pnpm install
```

3. Run unit and integration tests:

```bash
pnpm test
```
