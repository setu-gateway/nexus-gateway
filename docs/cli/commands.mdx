# Command Reference

Available commands for managing your Nexus Gateway instance:

- `nexus start`: Start the local gateway instance.
- `nexus status`: Check gateway health and connected providers.
- `nexus keys list`: List active API keys.
- `nexus keys create`: Provision a new API key.
- `nexus logs`: Stream request and system logs.
