# Response Caching Architecture

Reduce model latency from 1.5s to < 10ms and save provider costs by caching prompt completions.

## Cache Types

- **Exact Match Caching**: Keyed by SHA-256 hash of model name, prompt messages, and parameters.
- **Semantic Caching**: Uses vector similarity embeddings to match conceptually identical prompts.
