# Plugin Lifecycle Hooks

Every request flows through standard plugin execution phases:

1. `onInit`: Plugin initialization on server startup.
2. `onRequest`: Invoked before routing to provider.
3. `onResponse`: Invoked after receiving provider response.
4. `onError`: Triggered on request failure or timeout.
