# Plugin System Overview

Nexus Gateway features a modular plugin architecture for extending request processing pipelines.

## Plugin Types

- **Provider Plugins**: Custom LLM model integrations.
- **Auth Plugins**: Third-party authentication mechanisms.
- **Analytics Plugins**: Export request metrics to custom telemetry sinks.
- **Billing Plugins**: Rate limiting and usage accounting.
- **Notification Plugins**: Webhook alerts on errors or budget thresholds.
