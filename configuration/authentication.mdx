# Authentication & Access Control

Protect your gateway endpoints with API keys or JWT tokens.

## API Key Authentication

Pass your Gateway API Key in the `Authorization` HTTP header:

```bash
Authorization: Bearer <YOUR_NEXUS_GATEWAY_KEY>
```

## Role-Based Access Control (RBAC)

Restrict model access or token budgets by user role or organization team.
