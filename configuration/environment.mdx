# Environment Configuration

Configure your Setu Gateway instance using environment variables.

| Variable | Description | Default |
| --- | --- | --- |
| `PORT` | Listening port for the Gateway API server | `8000` |
| `REDIS_URL` | Redis connection URL for caching and rate limiting | `redis://localhost:6379/0` |
| `DATABASE_URL` | Database connection URL for configuration and telemetry | `postgresql://user:pass@localhost:5432/setu_db` |
| `LOG_LEVEL` | Application logging verbosity (`debug`, `info`, `warn`, `error`) | `info` |
