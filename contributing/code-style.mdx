# Code Style Guidelines

- **TypeScript / Node.js**: Format with Prettier, enforce ESLint rules, and write strict type definitions.
- **Python**: Follow PEP 8 guidelines and format with Ruff / Black.
- **Documentation**: Write clear, active-voice MDX documentation following standard Mintlify structures.
