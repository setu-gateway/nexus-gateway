# `POST /v1/chat/completions`

Generates model completions for a sequence of conversation messages.

## Request Body

```json
{
  "model": "gpt-4o",
  "messages": [
    { "role": "system", "content": "You are a helpful assistant." },
    { "role": "user", "content": "Explain quantum computing in one sentence." }
  ],
  "temperature": 0.7,
  "stream": false
}
```
